## L0 规则预清洗（更新版）

目标：只清理**确定性、无语义的字符级/行级噪声**，不碰内容本身。

**字符级清理**

1 **Emoji 与符号字形**
   - 移除 Unicode `So`（其他符号）、`Sk`（修饰符号）类字符：😀、✅、▶️、⭐ 等
   - 移除 Private Use Area（`\uE000–\uF8FF`）：样本里出现的 `\ue60b \ue60b` 就是这类（见 `run_1359b7...` 第一条 `web_search` 返回里的 "HD中字 [...]  ️"）
   - 移除 variation selector（`\uFE0F`）和 ZWJ`\u200D`）——这两个不可见，但会留在 token 流里
   - 实现：逐字符 `unicodedata.category()` 判断，或单条正则；**保留 CJK 标点**（。《》、「」，`Po`/`Ps`/`Pe` 类不动）

2. **制表符与空白**
   - `\t` → 统一替换为 2 个空格（搜索结果里制表符常出现在标题/URL 缩进位，直接删会粘连文本）
   - `\r\n` / `\r` → `\n`
   - 行尾尾随空格删除
   -3 个以上连续空行压缩为 1 个空行

3. **控制字符**
   - 移除 ANSI 转义序列（`\x1b[...m` 等，shell 工具输出常见）
   - 移除不可见控制字符（保留 `\n`）

**行级清理**（沿用原设计）

- 逐字符重复行去重（如样本里演员表 "闫妮\n\n闫妮" 重复块）
- 全空白行折叠

**确定性 UI 噪音整行**（新增，见 `_NOISE_LINE_PATTERNS` / `_SYMBOL_RUN_LINE_RE`）

- 只匹配 strip 后的整行，不碰正文中的同名片段：
  - 加载占位：`正在加载...`、`加载中...`
  - 占位文案：`节目还没有准备好，晚点回来再试试～`
  - 登录引导：`登录后可专享`、`帐号登录`
  - 站点 UI 骨架：`奇秀直播`、`相关推荐 换一组`、`回到顶部`
- 单符号长串整行：同一非文字字符重复 ≥ 10 次（`^^^^^^^^`、`======` 等）整行删除

**明确不做的事**

- 不删整段内容、不截断、不按**语义性**关键词过滤——语义判断全部留给 L1；
  上表的确定性 UI 噪音短语除外（任何语境下都不携带任务信息，误删风险为零）
- 不改数字、日期、URL、标点的原始形式

L0 是纯函数，对任意工具输出幂等执行；清洗前后数差记入 `l0_chars_removed` 统计。LLM 看到的 `raw_output` 和兜底保留的内容，都是 L0 之后的版本。

方案其余部分（L1 锚点摘要、质量门、失败保留完整内容、点、缓存、pilot）不变。
