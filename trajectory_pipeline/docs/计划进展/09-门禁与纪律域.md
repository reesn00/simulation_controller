# 09 · 门禁与纪律域

**职责：** 测试门禁的计数口径、skip 陷阱、「绿灯 ≠ 验过」这条元纪律。
这不是一个代码模块，是**每个模块都要守的那层**。

**核心纪律：** **任何新功能落地必须配 contract（测试即文档），否则走特殊审批。**
新 contract = 新守门人，是质量与回归的双重保障。

## 当前状态

```powershell
uv run python -m pytest -q
# → 2299 passed / 1 failed
```

**唯一 fail**：`test_xlsx_backfill` 的既有环境缺失——仓库根
`黄金集人工复核工作单-23/254条.xlsx` 不在本工作区。
`test_至少一份xlsx存在` 的设计是「双删则跳过（不挂 fail）」，
所以是 **1 fail 而非 skip**。**与任何增量无关**，各增量章节都标注了
「xlsx 既有环境缺失，与本批无关」。

⚠️ **报门禁数字时要把 skipped 一起报**——「全绿」在有 skip 时不成立。

## ⚠️ 门禁绿灯 ≠ 代码被验证过

**2026-10-11 实测（跑完第一批真实数据后）：1447 passed + 1 skipped；
变异测试 40/40 全部变红。**

⚠️ **这 1 条 skip 不是「数据不在」**，而是条件失效——
`test_code_scorer.py` 要一份**没有 `steps[]` 的老形状存档**，
而现有存档全都带 `steps[]`，找不出这样的样本。属设计使然，不欠验证。

### 22 条 skip 是怎么来的

**这一条是花 22 条换来的**。跑数据之前门禁是 `1340 passed + 22 skipped`，
那 22 条全是「**数据不在就静默 skip**」：

| 测试 | 条数 | 它验的是 |
|---|---|---|
| `test_code_scorer.py` | 3 | D-2 在真实 P1 上的行为 |
| `test_p1_contract.py` | 3 | P1 契约的**真实存档**核 |
| `test_d4/d5/d6_scorer.py` | 9 | 三个评分器对真实 P2 |
| `test_dom.py` | 4 | obscura DOM 实测存档（2 个文件 × 2 条）|
| `test_p2_contract.py` | 1 | P2 契约的**真实存档**核 |
| `test_replay.py` | 1 | 感知层回放 |
| `test_rationale_gates.py` | 1 | rationale 闸门 |

⚠️ **这是 [CLAUDE.md 那条教训的同构复现**。原来是「gdr/tests 漏在
门禁外，360+ 条不跑」；这次不是漏在门禁外，而是**数据不在就 skip**——
门禁照样显示全绿，CI 不会报警，而那 22 条从未执行。

**恢复它们靠的不是写测试，是跑数据**（`cli run` → `cli build` → `probe_returns.py`）。

⚠️ **下一次清空 `output/pipeline/` 会让这 21 条重新 skip。**

> 同构的第三处：**`evaluation.cli` 在 0 数据下输出「0 份存档 → 0 条样本」
> 且不报警**——数据为空与一切正常在报表上同形。真要修，判据是
> 「读到 0 份存档」而不是「读到 0 条样本」，但那是独立一条，**未做**。

### 第四处同构风险：`testpaths` 门禁接线

```toml
testpaths = ["trajectory_pipeline/tests"]
```

**门禁必须显式枚举每一棵在开发的树，漏一棵 = 静默失效不可见。**
v1 测试树 2026-10-09 随代码归档退役出默认门禁，手动跑法见
[`archive/v1/README.md`](../../../archive/v1/README.md)。

## 测试即文档：每个增量的「预期与实际」模板

各增量章节的验收小节固定回答四个问题（**这是本文档出现频率最高的模板**）：

| 指标 | 预期 | 实际 | 判定 |
|---|---|---|---|

**纪律**：预期值在跑之前写死，跑完填实际值。**预期和实际对不上就写出来**，
不要改预期去迁就实际。
