`trajectory_pipeline/output/pipeline/`（决策 D8）。读了根 `output/` 就继承了
v1 那套隐性耦合。

## INC45 · E005 轨迹结构三重修复（2026-10-15）

E005__e35b7455__site-4 被 scout 判 positive 但轨迹三处结构缺陷：

   `steps[].observation` 逐位构建；null 顶
   `MISSING_OBSERVATION = {"degraded": ["observation_missing"]}`

2. **P3 任务总结收尾**（`assembler/views.py`）：`_closing_text` 从

   分支词表，`TestClosingDispositionDrift` 契约盯漂移；空轨迹不编
3. **infra 整步不进消息视图**：`origin=="infrastructure"`（new_tab）
   动作+观察+思考一起跳过；tool_call_id 按可见步稠密派生

顺手修两处隐患：**rationale 稀疏串位**（views 改按 step_index dict
查找）与**悬空 tool_call**（缺观察显式渲染占位回执
「（本步没有取到页面内容）」）。D-4 侧加 `_is_missing` 防 §5.14
回潮（末位占位 → `_player_obs` None；同页比较只算真实观察）。

**契约同步**：[`../contracts/P3-views.md`](../contracts/P3-views.md)
六条→**八条**关键判断；meta 加 `missing_observation_count` /
`closing_summary` 两键（15→17）。

**验收**：全量门禁 **2328 passed**（基线 2296 + 净增 32）；P2
304/304、P3 912/912 重建；302/304 带收尾；缺失占位 126；**scout
重跑分流零变化**（pos=49 逐条一致，E005 site-4 仍全 5）。
完整根因与产物见 [90-增量编年史](90-增量编年史.md#增量四十五--e005-轨迹结构三重修复inc452026-10-15)。
