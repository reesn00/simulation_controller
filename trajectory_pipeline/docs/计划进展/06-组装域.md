# 06 · 组装域

**职责：** P1 → P2 → P3 三段落盘。对应
[架构总览](../01-架构总览.md) 的**模块 5 组装层**。落点是
[`assembler/`](../../assembler/) 与 [`storage/`](../../storage/)。

**核心纪律：** **产物隔离**——新树**禁止读取仓库根 `output/`**，产物全部落
`trajectory_pipeline/output/pipeline/`（决策 D8）。读了根 `output/` 就继承了
v1 那套隐性耦合。

## P3 三视图

| 视图 | 读什么 |
|---|---|
| `source` | 原始观察面（source 侧）|
| `view` | 渲染后视图面 |
| `truncated` | 元素裁剪面（`{'source': False, 'view': False}`）|

⚠️ **`truncated` 是 dict 不是 bool**——这是 INC42 的假阳性根因，
四处 `_observation_shortfall` 各自加了 `_truncated_flag` 修复。
见 [05-rationale与闸门域](05-rationale与闸门域.md#缺陷一truncated-字典假阳性四处同步)。
