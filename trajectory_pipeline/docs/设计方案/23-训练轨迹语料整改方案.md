## 0. 速览

### 0.1 一句话

**这批数据作为「证据与归因材料」是可靠的，作为「训练语料」有四处硬伤。**

证据侧的地基全在：观察是真回放（不是 LLM 转述）、分支由代码记账、
fail-closed 不硬编结论、工具声明单一真源。
语料侧坏在四件事上，**按危害排序**：

| # | 硬伤 | 一句话 |
|---|---|---|
| **S1** | **交付出去的「思考」不是探索者的思考** | 动作是 agent runtime 选的，但配对的动作理由是**访问结束后另一个 LLM 补写的**；且补写时的 history 作用域是**站点单元**而不是 run ⇒ 补出来的文本在组装后的对话里**自相矛盾** |
| **S2** | **终局答复是内部记账语言，且不满足自己的 `output_contract`** | 89.8% 的生产样本，任务明写「回复必须含可播放网址」，最终答复里**一个 URL 都没有** |
| **S3** | **观察是整页快照，噪声压倒信息** | 单条回执 1000~3000 字，任务相关不足 10%，其余是热搜榜 / ICP 备案号 / 页脚 / 广告 / 推荐流 |
| **S4** | **重复动作在教「再点一次」** | 469 处「相邻同动作 + 观察逐字相同」；38% 的步是重复动作 |

> **S1 与 S4 的性质不同**：S1 是**执行层写错了**（补记覆盖了原生 think），
> S4 是**数据筛选没做**（死循环步没剔）。前者要改代码，后者要加闸门。

### 0.2 为什么要做（四个缺口）

| # | 缺口 | 证据 |
|---|---|---|
| **G1** | **语料里的 CoT 不是 agent 的 CoT。** 生产面 4852 步里，`rationale.reason` **没有一条是 `native-think`** —— 4850 条是事后补记的 writer 产物、2 条是 writer 失败的标记。agent 决策时写下的原生 think（`agent_loop.py:583` 封的 `reason="native-think"`）**在 P1 里一条都没留下** | §1.2 |
| **G2** | **补记出来的文本与它自己的上下文打架。** 生产面 235 步说「没有历史 / 首次操作」，其中 **225 步前面已经有观察消息**、**202 步前面已经有 ≥3 条** —— 也就是说，模型被教「无视对话历史、每步都重新开始」 | §1.3 |
| **G3** | **收尾的话不是给用户的话。** 131/131 的 P3 末条 assistant 与 65/65 的 T 末条 assistant 都是代码合成的「任务总结：…处置：…分支分布：…」；分支枚举名 + 计数是**并池决策口径**，不是助手语言；`login_wall_or_blocked` 这样的 **deprecated 分支**也在里头 | §1.4 |
| **G4** | **终局验收不看最终回复。** 「回复必须含可播放网址」写在 `output_contract` 里，但闸门只判 `outcome`，**不读回复文本** ⇒ 44/49（89.8%）违约，而 `gate` 仍判 `passed`（102/131） | §1.4 · §2.7 |

### 0.3 三条不做（划边界，越界即架构回退）

1. **不改执行层的探索权归属。** 「LLM 层做探索、代码层做护栏」这条不变——
   本方案要修的是**交付出去的语料长什么样**，不是**谁做决策**。
   动作仍然由 agent runtime 选（§1.2 实测 `origin=model` 4071 步）。
2. **不回填历史存档。** 新分支 / 新口径**不倒灌**存量：存量 131 份样本
   **保持原样**，整改只对**新批次**生效（并池是写入时的动作，不是读取时的推导）。
   ⇒ 存量那 44 条违约样本**留在证据区，不进训练区**。
3. **不动评估侧。** D-10 / 黄金集 / LS 上传口径一概不动；本文只在
   「语料能不能用」这一格上提要求。✅ **O-4 已裁（2026-11-02）：人核链只接
   per-Run 轨迹，金标那条线不动**。

### 0.4 五个最要紧的判断

| # | 判断 | 影响面 |
|---|---|---|
| **D1** | **补记不得覆盖原生 think。** `attach_rationale` 现在是无条件替换（`actions.py:318`），而 `_write_rationales` 对每个候选站无条件调用（`orchestrator.py:1305`）⇒ agent 模式下原生 think **必被顶掉** | 决定 CoT 语料是不是真的（§3 R0） |

① **补记的 history 作用域**（单元级）；② **交付时的对话拼接**（run 级）。
