每条命令「联网与否 / 作用 / 参数」、环境变量、门禁与输出目录见
[运行手册](04-运行手册.md)；开发纪律见仓库根 [`CLAUDE.md`](../../CLAUDE.md)。

## 必填项：缺了就报错，不猜

| 命令 | 缺什么会报错 | 备注 |
|---|---|---|
| `run --task-id … ` | **`--title`** | 缺省即报错，**不拿 `--task-id` 顶替**——少了它会搜成 `T001 在线观看`（**轮胎** T001），产出整批理由通顺的假负样本且**零报错**（[避坑指南 §5.13](02-避坑指南.md)） |
| `run --driver obscura` / `check --driver obscura` | `OBSCURA_EXE` | 缺失即报错，**不猜路径**。`setx` 只对新终端生效。⚠️ **只显式点名 obscura 才需要它**——缺省执行层是 camoufox（2026-10-22 owner 裁定），走进程内 API，**不依赖 `OBSCURA_EXE`** |
| `run --per-site-timeout` | 非正数 | `0` / 负数 / 非数字 / `inf` 一律报错。0 的业务含义是「立刻超时」⇒ 会产出一批**看起来正常的空批** |
| `--perceptor llm` / `TRAJECTORY_PERCEPTOR=llm` | `TRAJECTORY_LLM_BASE_URL` / `_MODEL` / `_API_KEY` | 同样缺失即报错不猜；`TRAJECTORY_LLM_TIMEOUT_S` 默认 **90s**、`TRAJECTORY_LLM_MAX_TOKENS` **采集时设 16384**（见[运行手册 §环境变量](04-运行手册.md#环境变量)） |
| `--executor-mode agent` | 同上 `TRAJECTORY_LLM_*` | **不静默退回 scripted**——那会让「agent 批失败了 40%」被读成「scripted 跑得好好的」 |
| `downgrade` | `--reason` | 必填，原样进 `evidence`；**默认 dry-run**，看完清单再加 `--apply` |
| `relabel` | `--reason` + `--url`/`--branch`/`--evidence` 之一 | 理由必填（原样进 `evidence`）；**不给判据就是全选**，拒绝执行；`--to` 必须是**活跃且是真负样本**的分支（`unresolved` 等反思档不走这条）；**默认 dry-run**，看完清单再加 `--apply` |
| `pool-drop` | `--reason` + `--url`/`--task-id`/`--branch` 之一 | 理由必填（进 `pool_dropped.jsonl` 审计日志）；**不给判据就是全选**，拒绝执行——池是 append-only 资产，**全选等于清空训练集**；**默认 dry-run**，看完清单再加 `--apply` |
| `pool-add` | **没有必填项**（`--out` 缺省 = 生产目录） | **默认 dry-run**，看完清单再加 `--apply`；**只动池、不动存档**；**口径与门禁一致**（跑完 `check-archives` 不再报 `negative_not_pooled`）；**幂等**；三条拒并条件（**已拒收** / **与成功记录矛盾** / **池内留着手工改判的旧行**）命中就**跳过并打印冲突**——**分歧不替人投票** |
| `calibration.verify` | `--baseline` 与 `--current`（或 `--baseline-version` 与 `--current-version`）**各恰好一个** | 两边都给路径又给版本、或一边也没给，一律退 2。给了 `--triage` 就必须给 `--bucket`（分诊表脱离目标桶没有意义）。**退出码是结论**：`0` 过 / `1` 驳回 / `2` **输入不可比**（工具故障、切分变了、键对不上）——**1 与 2 不许混报**，否则「测不成」会被读成「回退」 |
| `calibration.gate` | 没有基线、基线与本轮同版、或指定了不存在的版本 | 一律退 2，**不拿"首版"当通过**。触发点是 **freeze**，不是每次 push——快照的 pred 侧取自冻结行，同一版对同一版恒为净改善 0，按 push 跑的门永远红 |
| `calibration.triage add` | `--by`（签名）+ `--evidence`（判据）+ `--bucket`（必须是**六桶之一**） | **缺一样就不写**：签名是追溯的主体，证据要写清「为什么是这个桶、为什么不是别的桶」。`--bucket` 不在六桶内（含 `other` / `accepted_exception`）直接退 2——`accepted_exception` 是**状态**不是桶。`--by agent…` 而桶是 `rubric_*` / `gold_defect` 一律拒：**这两类只能人填**（D-C3），agent 只能写卡上的建议值。改已有行必须 `--replace`（覆盖审计在 git） |
| `calibration.worklist build` | `--version`（冻结版本号）**并且先跑过 `agreement --emit-disagreements`** | 卡不存在 = **退 2**（不是"这批全都一致"）。工作表已存在时**不覆盖**，要重来加 `--overwrite`——人填到一半被冲掉是这里最贵的损坏。工作表**每行带 `scene` 栏**（现场读数：页面标题 / 每步观察 / 正文预览），读不到就在表里明说「读不到」——**没有现场可看就没法判桶** |
| `calibration.triage import` | 工作表三栏（`bucket` / `triage_by` / `triage_evidence`）**逐行填满** | 半填的表**整批拒**并逐条列出缺哪几行——不做"填几行写几行"，那种行为会让覆盖率看起来在涨，涨的只是填表耐心 |
| `calibration.worklist show` | `--golden-id <ID>` **或** `--all`（两者都不给 = 退 2） | **只读**，不写分诊档。ID 不在本轮卡里 → 退 2（并说清是"不是分歧卡"还是"版本对不上"）。**定位不到现场时给「读不到 + 候选清单」，不给空读数**——空读数会被读成「页面里没有 video 标签」 |
| `calibration.goldwork worksheet` | `--version`（冻结版本号）；`--split` 必须是三档之一 | 表已存在时**不覆盖**（人填到一半被冲掉是这里最贵的损坏），重出加 `--force`——已填的格子按 `(golden_id, dimension)` 预填回来，重出不会让人再填一遍（L-19 的口径）。这一档一条「有样本」的行都没有 → **退 2**，不产空表 |
| `annotate --dimensions-only` | 输入里**至少一个填好的格子** + 每个填了分的 `golden_id` 要有 `reviewed_by` | 整张表空格 → **退 2**（`没填不是判不了`：判不了写 `null`，没看就留空）；`golden_id` 在 `annotations.jsonl` 里没有 round=1 标注 → 退 2 并**列出全部缺失**（分数不能凭空造样本）；改已有分数不加 `--force` → 退 2（同键同值算幂等跳过，**不算改动**） |
| `annotate`（整行模式） | `label` + `reviewed_by` + **`access_surface` + `observed_at`**（方案 20 §R2 / O-d：断言标签就得说清在哪张面、什么时候看的） | 缺 `access_surface` → 退 2 并列出**两种合法来源**（`human-browser` / `camoufox-plain`·`obscura-plain`）；面代号认不出（如 `camoufox-default`）→ 退 2 并列合法值，**不当成「没记」**；缺 `observed_at` 或不是 ISO-8601 → 退 2。**没开浏览器也没有存档证据 ⇒ 这一行不该有 label**。旧行不回填：冻结时没有这一栏的落 `unrecorded` |
| `freeze --refresh-gold` | 必须配 `--from-version`；annotations 里**至少一条软维度分数** | 单独用 → 退 2（不继承的冻结本来就直读 annotations）。一条分数都没有也退 2：**刷空等于什么都没做，却把版本号用掉了**。⚠️ 它写 `gold_refresh.baseline_reset=true` ⇒ **金标变动 = 新基线**，`gate` 读到就退 2 |
| `calibration.triggers` | `--version` **并且先跑过 `agreement`**（快照在 `v{N}/snapshot.json`） | 快照不存在 → **退 2**（不是"这批都一致"）。`--judge-report` 的行**必须自带 `golden_id` + `dimension`**：缺键直接退 2，**不按 `sample_id` / url 猜**——猜出来的键会让 kappa 建在配不上的分母上。T-3 不给 `--quote-marker` 就**测不成**（"理由非空"≠"理由有据"） |
| `calibration.sampling` | `--version` **并且先跑过 `agreement`**；`--quota ≥ 1` | 快照不存在或一条都抽不到 → **退 2**。**配额缺口不补**：层候选不足就少给并报 `short_by`，跨层借人会把 40 条看着齐了而实际同质 |
| `rubric_changelog audit` | `--before` 与 `--after` **各恰好一个**，且两版快照都得在 | 缺快照 / schema 不合 / 两版 `rubric_version` 相同 / 区间里没有变更记录行 → **退 2**。⚠️ **受检条款一条都没配上也是 2**（`0 条样本 ≠ 一切正常`）：`freeze --from-version` 把两版分数原样带过来时，这条判据会**空跑** |
| 改 rubric 条款 | 变更记录表里**加一行**（九列全填：条款 / 变更类型 / 变更内容 / 预期效果 / 分歧卡 / 责任区分声明 …） | 升 `RUBRIC_VERSION` 而不加行 → `check` 退 2；「以评估器做不到为由」→ **驳回**。列契约见 [rubric 文档](设计方案/在线视频场景rubric.md) |

**key 只走环境变量**：代码里没有任何凭据字面量，`LLMConfig.__repr__` 刻意不吐 key，
`test_llm.py::TestNoCredentialInSource` 盯着源码里不许出现 `sk-` / `bgw_` 这类前缀。
