## 二、架构与交互速览（读问题前的坐标）

### 2.1 五层与依赖

```text
taskgen → executor → assembler → storage
              ↑          ↑
          perception  evaluation（反向 import，刻意例外）
common / llm / toolcatalog / outcomerules / projection 是跨层地基
```

四条不可破的边：`executor` 只依赖感知协议；`perception` 不 import `executor`；
`executor` 不 import `llm`；`assembler` 不 import `executor`。均由 AST 契约测试盯着。

### 2.2 一次 run

```text
Orchestrator.run
  ├ 0   goto(search_url) + observe
  ├ 0.5 detect_block（反爬先于取候选）
  ├ 1   result_titles + extract_candidates
  ├ 1.5 Q.CLASSIFY_SEARCH_LINKS（分批）
  │      direct → 首页候选记 not_play_site 后丢
  │      B/C    → 中间页（aggregator/article）
  └ 2   for 候选 → _visit_guarded
          scripted: enter_site → Q② → Q③ → open_tab → click → observe → Q④
          agent   : enter_site → open_tab → agent_loop → Q④
  → _seal → P1Archive.write（凭据扫描 + 真负样本并池）
```

agent 循环七步：**预算 → 决策 → done 出口 → 执行 → 复观察 → 死循环/拦截 → 记账**。
agent 只报 `reached / gave_up / fail_closed` 三形态，分支由代码查表折算。

### 2.3 数据链

```text
P1（证据）
  → P2（一条 run 一条轨迹；动作摊平；观察渲染；任务级 outcome=末条结论）
  → P3（messages / openai / meta）
  → T（per-run 任务视图，独立渲染）
  → 负样本池 / 精炼旁挂 / 评估（scout / 黄金集 / 校准）
```

P1 是证据态；P2/P3 是训练态；`refine` 只产出旁挂，P1 一个字不动。
「证据」与「语料」分离是本项目最值钱的设计，下面的多数问题都发生在
**两者的接缝处**。

### P0-1 · `open_tab` 后不重新枚举 ⇒ 首步 click/fill 静默空转、观察跨页

| 项 | 内容 |
|---|---|
| 落点 | [`agent_visit.py:109`](../executor/steps/agent_visit.py#L109) / `:135`；[`visit.py:238`](../executor/steps/visit.py#L238) / `:253`；[`camofox_driver.py:1471`](../executor/browser/camofox_driver.py#L1471) / `:409` / `:936` / `:1121` |
| 判据 | 驱动面：`{role,name}` 的定位依赖 `_target_index`，而它由 `interactive()` 建立；`new_tab` 调 `_reset_page_state()` 清空它。 |

**链路**：

1. `enter_site` 在**旧 tab** 上 `observe`，得到 `site_obs`（含元素清单）；
2. `open_tab` 新建 tab 并导航，`_reset_page_state()` 清空 `_refs` /
   `_camo_refs` / `_target_index`；
3. agent 拿**旧 tab 的** `site_obs` 作为 `initial_obs`，第一步决策按旧清单选目标；
4. `driver.click(role, name)` 查 `_target_index` → 空 → `_miss("not_found")`；
   `click` 在 `:936-938` **直接 return，不抛错**；
5. 该步被记成成功（`error` 为空），随后 `observe` 才重新枚举；
6. scripted 链没有第二次点击，直接进 `judge_player`。

**影响**：

- 每个 agent 站点第一步的 click/fill 是**没有发生的动作**；
- 观察来自新 tab，动作目标来自旧 tab，**动作与观察不同源**；
- scripted 链上需要点击的站点会系统性判不出来（`unresolved` 或同页降级）；
- 训练视图里可能留下一条“点了但页面没变”的 no-op 步。

**建议**：`open_tab` 成功后立即 `observe()`（并重新 `interactive()`），用新观察
作为 `initial_obs`；或至少把“重新枚举”作为开 tab 的一部分，不能靠第一步动作
替它完成。scripted 链同款。

## 六·补 · 变异清单漂移（2026-11-24 修 P0-2 时发现）
